today's outcome

By the end of this class you can connect a Java program to a relational database with JDBC and implement basic CRUD for a Student.

setup checklist

  1. Install Java 17 or later and verify with java -version.
  2. Install IntelliJ IDEA, Maven, Git, MySQL or PostgreSQL, and Postman.
  3. Create a plain Maven Java project. Do not add Spring yet.
  4. Create a database and a students table.

For the official project generator used later, bookmark start.spring.io. The official REST service guide also lists Java 17+, Maven, and IntelliJ as the baseline.

the database model

CREATE TABLE students (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(150) UNIQUE NOT NULL,
  branch VARCHAR(80) NOT NULL
);
public class Student {
    private Long id;
    private String name;
    private String email;
    private String branch;
}

the JDBC pipeline

The application does not talk to MySQL directly. A JDBC driver translates the standard Java database calls into the database's protocol.

🧷 remember
Java code → JDBC API → JDBC driver → MySQL/PostgreSQL.

read one student

String sql = "SELECT id, name, email, branch FROM students WHERE id = ?";

try (Connection connection = dataSource.getConnection();
     PreparedStatement statement = connection.prepareStatement(sql)) {
    statement.setLong(1, studentId);

    try (ResultSet result = statement.executeQuery()) {
        if (result.next()) {
            Student student = new Student();
            student.setId(result.getLong("id"));
            student.setName(result.getString("name"));
            student.setEmail(result.getString("email"));
            student.setBranch(result.getString("branch"));
            return student;
        }
    }
}
return null;

why preparedstatement?

Never concatenate user input into SQL. A PreparedStatement sends the SQL structure separately from the values, which helps prevent SQL injection and handles escaping correctly.

// unsafe
String sql = "SELECT * FROM students WHERE email = '" + email + "'";

// parameterized
String sql = "SELECT * FROM students WHERE email = ?";
statement.setString(1, email);

the four CRUD operations

  • Create: INSERT with executeUpdate().
  • Read: SELECT with executeQuery() and ResultSet.
  • Update: UPDATE with changed parameters.
  • Delete: DELETE with a parameterized identifier.
⚠️ gotcha
Close connections, statements, and result sets. Try-with-resources closes them even when an exception occurs.

the motivation for ORM

For one table, manual mapping is manageable. With 50 entities, every query repeats connection handling, SQL strings, column names, and row-to-object mapping.
