Spring's main feature is not an annotation; it is letting the container manage relationships.

today's outcome

You will understand Spring IoC, dependency injection, beans, component scanning, and what Spring Boot adds on top of the Spring Framework.

the problem without Spring

public class OrderService {
    private final PaymentService paymentService = new PaymentService();
}

This class chooses the concrete dependency, constructs it, and owns its lifecycle. Testing and replacing that dependency becomes harder.

inversion of control

With IoC, your application does not create every object itself. The Spring container creates configured objects, called beans, and supplies their dependencies.

Spring container
  PaymentService bean
          ↓
  OrderService bean
          ↓
  OrderController bean

constructor injection

@Service
public class OrderService {
    private final PaymentService paymentService;

    public OrderService(PaymentService paymentService) {
        this.paymentService = paymentService;
    }
}

Constructor injection makes required dependencies explicit, supports immutable fields, and makes unit tests straightforward.

⚠️ gotcha
Do not add new PaymentService() inside a Spring-managed class when you expect Spring configuration, proxies, or injected dependencies to apply.

common bean annotations

AnnotationRole
@ComponentGeneral Spring-managed component.
@ServiceComponent whose role is application/business logic.
@RepositoryComponent used for persistence access.
@ControllerMVC controller that returns a view.
@RestControllerController whose return values become response bodies.
@Configuration + @BeanExplicit Java configuration.

Spring Boot

Boot aims to create stand-alone, production-grade Spring applications with minimal configuration. Read the official Spring Boot reference for the full feature map.

springapplication

@SpringBootApplication
public class StudentApplication {
    public static void main(String[] args) {
        SpringApplication.run(StudentApplication.class, args);
    }
}

Conceptually, @SpringBootApplication combines configuration, auto-configuration, and component scanning. It is a convenient starting point, not magic that replaces understanding.

practice

  1. Create an interface PaymentGateway and inject it into OrderService.

  3. Write a unit test that supplies a fake payment gateway without starting the Spring server.
