spring boot · from database calls to production-shaped services

Build backend systems you can explain

Ten focused classes. We start with JDBC so the framework solves a real problem, then move through JPA, Spring Boot, REST, production practices, and microservices. Days 11 and 12 remain reserved for the project phase.

By the end of this course, you know:
  1. Why Spring Boot exists and what it automates
  2. The difference between JDBC, ORM, JPA, Hibernate, and Spring Data JPA
  3. How IoC, dependency injection, beans, and component scanning work
  4. How to build and test a layered REST API
  5. How repositories, entities, DTOs, relationships, and transactions fit together
  6. How to validate requests and return consistent API errors
  7. When a monolith is better than microservices
  8. How discovery, load balancing, gateways, resilience, and observability fit together

One rule for every Spring annotation: explain the problem it solves.

Use the framework to remove repetition, not to hide the request flow, database behavior, or failure modes.

“Understand the layer underneath the annotation.”
