how to get the most out of these notes

Three golden study rules:
  1. Trace the hardware step-by-step: Never memorise an abstract definition. Trace what the CPU registers, stack pointers, and MMU are doing at each clock cycle.
  2. Solve the numerical traces by hand: Calculate page address translations, effective memory access times (EMAT), Banker's safety vectors, and scheduling Gantt charts yourself.
  3. Connect code to kernel syscalls: When writing high-level Java, Python, or Go, ask yourself: "Which syscall is this invoking? Does it switch to kernel mode? Does it allocate a physical frame or just bump virtual memory?"
