blindfolded on a hill, one rule: step downhill. repeat till flat. that's it — and it powers everything.

the 30-second idea

From your pages 6–9: gradient descent finds the w,b that minimise J. Loop two lines until the hill goes flat:

$$\begin{aligned} w &:= w - \alpha\,\frac{\partial J}{\partial w} \\ b &:= b - \alpha\,\frac{\partial J}{\partial b} \qquad (\alpha = \text{learning rate}) \end{aligned}$$

That ∂J/∂w is just the slope under your feet. Steep slope → big step. Flat (slope 0) → stop, you are at the bottom.

the intuition your notes drew — sign tells direction

  • Slope positive (+) → $w := w - \alpha\cdot (+)$ → w decreases → slide left, toward the bowl.
  • Slope negative (−) → $w := w - \alpha\cdot (-)$ → w increases → slide right, toward the bowl.
  • At the bottom → ∂J/∂w = 0 → w := w − 0 → frozen. Local minima = nap time. 😴

learning rate α: baby steps vs cliff jumps

🧷 remember
Gradient descent auto-brakes: slope gets smaller near the minimum → steps get smaller → it coasts in without you touching α. That sentence your notes underline is the single most-quoted intuition in viva.

the actual derivatives (page 9, no fear)

Your notes derive these line by line — here is the landing spot. Same pattern twice, the w one just carries an extra x⁽ⁱ⁾:

$$\frac{\partial J}{\partial w} = \frac{1}{m}\sum_{i=1}^{m}\left(f_{w,b}(x^{(i)})-y^{(i)}\right)x^{(i)} \qquad \frac{\partial J}{\partial b} = \frac{1}{m}\sum_{i=1}^{m}\left(f_{w,b}(x^{(i)})-y^{(i)}\right)$$

Read it as: average miss, weighted by x for w, plain for b. Plug into the two update lines, loop. Combine all three pieces from page 8:

$$\begin{aligned} \text{model: }& f_{w,b}(x)=w x + b \\ \text{cost: }& J(w,b)=\frac{1}{2m}\sum_{i=1}^{m}\left(f_{w,b}(x^{(i)})-y^{(i)}\right)^{2} \\ \text{update: }& w := w-\alpha\frac{1}{m}\sum_{i}(f-y)x^{(i)},\;\; b := b-\alpha\frac{1}{m}\sum_{i}(f-y) \end{aligned}$$

python — the exact notebook, cleaned and de-bugged

● ● ●python — cost + gradients (loop & vectorized)
import numpy as np

def cost_func(w, b, X, Y):
    """J(w,b) = 1/(2m) Σ (w·X+b − Y)² — vectorized"""
    m = X.shape[0]
    y_hat = w * X + b
    return (1/(2*m)) * np.sum((y_hat - Y)**2)

def compute_gradients(w, b, X, Y):
    """∂J/∂w , ∂J/∂b — vectorized (one-liners, no loops)"""
    m = X.shape[0]
    f_wb = w * X + b
    error = f_wb - Y
    dj_dw = (1/m) * np.sum(error * X)
    dj_db = (1/m) * np.sum(error)
    return dj_dw, dj_db

# loop twin — mirrors math Σ exactly, slower but viva-friendly
def compute_gradient_loop(x, y, w, b):
    m = x.shape[0]; dj_dw = 0; dj_db = 0
    for i in range(m):
        f_wb = w*x[i] + b
        dj_dw += (f_wb - y[i]) * x[i]
        dj_db += (f_wb - y[i])
    return dj_dw/m, dj_db/m
● ● ●python — gradient descent loop (the engine)
def gradient_descent(w_init, b_init, alpha, X, Y, num_iters):
    """
    w_init,b_init : start (often 0)
    alpha         : learning rate (0.001 to 0.1 typical)
    num_iters     : steps
    """
    w, b = w_init, b_init
    j_history, w_hist, b_hist = [], [w], [b]

    for i in range(num_iters):
        dj_dw, dj_db = compute_gradients(w, b, X, Y)
        w -= alpha * dj_dw          # simultaneous — use OLD gradients
        b -= alpha * dj_db
        w_hist.append(w); b_hist.append(b)
        if i % 100 == 0:
            j_history.append(cost_func(w, b, X, Y))
    return w, b, j_history, w_hist, b_hist

how to pick α — the 10× rule

In practice you sweep: try 0.001, 0.003, 0.01, 0.03, 0.1, 0.3, 1.0 (×3 each). Small α = snail, huge α = explosion. Plot J vs iterations — it should smoothly fall. If J jumps up and oscillates, α is too big → divide by 3. If J crawls, multiply by 3. This table from your notes logic:

αJ curvediagnosis
0.001slow glide downsafe but needs more iters
0.01fast dive then flatoften sweet spot ★
1.0oscillates / blows uptoo big → diverge
⭐ exam tip
If asked to "write gradient descent for linear regression", give all three blocks: model + cost + both updates with expanded sums and mention simultaneous update. Two update lines without the cost = half marks. Bonus: add "convex → one global minimum".
⚠️ gotcha
Update w and b simultaneously from the old values each iteration. Code pattern wrong: $w -= \alpha\cdot dw; dj_db = ... using new w \to bug$. Always compute dj_dw, dj_db first, then update both.
🔬 try it: one step by hand

One dot (x=2, y=4). Start w=0, b=0, α=0.1. f=0, miss=−4. ∂J/∂w = −4·2 = −8 → w := 0 − 0.1·(−8) = 0.8. ∂J/∂b = −4 → b := 0 − 0.1·(−4) = 0.4. New f(2) = 2.0 — miss shrank from 4 to 2 in one step. Try α=1.0 → w=8 → f=16 → miss 12 → worse! Feel α.

print(compute_gradients(0,0, np.array([2.]), np.array([4.]))) # (-8.0, -4.0)

quick check

  • Slope +5, α=0.1 — where does w go? Down by 0.5 (w decreases toward minimum).
  • α too big — symptom? J bounces up / diverges instead of falling.
  • When does it stop moving? Slope = 0 → update is w := w. Parked.

the 20-second answer

Gradient descent repeats w −= α·slope, b −= α·slope: positive slope steps left, negative steps right, zero slope naps. Small α crawls, huge α explodes, and near the bottom steps shrink by themselves (auto-brake). The linear-regression slopes are just average miss (× x for w). Cost always falls if α is sane — and for linear regression that fall lands at the global bottom. Next: many features at once → Multiple Regression.
