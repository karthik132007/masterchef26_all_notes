This page does the statistical (gaussian) route fully in code — it's the exam favourite and the building block for the others.

the gaussian bell (pages 31–32) — the formula you must write

$$p(x;\mu,\sigma)=\frac{1}{\sqrt{2\pi}\,\sigma}\exp\!\left(-\frac{(x-\mu)^{2}}{2\sigma^{2}}\right) \qquad \mu=\text{mean},\;\sigma=\text{std},\;\epsilon=\text{threshold}$$

the ε rule — the whole game in 3 lines

$$\text{fit }\mu,\sigma \text{ on NORMAL data }\to p(x);\quad \begin{cases} p(x)<\epsilon &\Rightarrow \text{ANOMALY}\\ p(x)\ge\epsilon &\Rightarrow \text{normal}\end{cases}$$

many features? multiply. correlated? go multivariate.

$$\text{Independent: } p(x)=\prod_{j=1}^{n}p(x_{j};\mu_{j},\sigma_{j}^{2}) \qquad \text{Multivariate: } p(x)=\mathcal{N}(x;\mu,\Sigma)$$

Multivariate uses Σ (covariance matrix), |Σ| (determinant), Σ⁻¹ (inverse) and the Mahalanobis distance $(x-\mu)^{\top} \Sigma^{-1} (x-\mu)$ — distance that knows features move together (height↔weight!). Derivation in exam: if Σ = diagonal → product = multivariate; if off-diagonal nonzero → correlation matters.

multi-feature ≠ multivariate  ·  product = assumes independence  ·  multivariate = models correlation via Σ ★

Your notes underline this distinction on the last page — it is the most quotable line of the bundle. Independent bells multiplied = cheap and often fine; one joint bell with Σ = correct when features conspire (height/weight, temperature/altitude).

python from scratch — 1-D + multi-feature + multivariate + ε tuning

● ● ●python — gaussian anomaly detector from scratch
import numpy as np
import matplotlib.pyplot as plt

def gaussian(x, mu, sigma):
    return (1/(np.sqrt(2*np.pi)*sigma)) * np.exp(-(x-mu)**2/(2*sigma**2))

def fit_gaussian(X):
    """X: (m,n) clean normal data → mu (n,), sigma (n,)"
    return X.mean(axis=0), X.std(axis=0, ddof=0)

def p_multivariate_independent(X, mu, sigma):
    """P(x)=Π_j P(x_j; μ_j,σ_j) — assumes independent features"""
    p = np.ones(X.shape[0])
    for j in range(X.shape[1]):
        p *= gaussian(X[:,j], mu[j], sigma[j])
    return p

# ── demo: 200 normal logins ~ N(2h, 0.5), plus a fraud at 12h
np.random.seed(0)
X_train = np.random.normal(loc=2.0, scale=0.5, size=(200,1))
mu, sig = fit_gaussian(X_train)
print(f"μ={mu[0]:.2f} σ={sig[0]:.2f}")

for x in [2.0, 3.0, 5.0, 12.0]:
    prob = gaussian(x, mu[0], sig[0])
    flag = "🚨 ANOMALY" if prob < 1e-4 else "✅ normal"
    print(f"x={x:4.1f}  P={prob:.2e}  {flag}")
# x= 2.0  P=7.9e-01  ✅   x= 5.0 P=1.2e-08 🚨   x=12 P≈1e-88 🚨
● ● ●python — multi-feature (2-D: height, weight) — product vs multivariate
# fake correlated normal data: height ~170±10cm, weight ~70±10kg, cor≈0.8
mean = np.array([170, 70]); cov = np.array([[100, 80],[80, 100]])
X_norm = np.random.multivariate_normal(mean, cov, size=500)

mu, sig = fit_gaussian(X_norm)                # for independent product
# for true multivariate, keep full Σ
Sigma = np.cov(X_norm, rowvar=False)

def p_multivariate_full(X, mu, Sigma):
    # P(x)= 1/( (2\pi)^(n/2)|Σ|^.5 ) * exp(-.5 (x-μ)ᵀ Σ⁻¹ (x-μ))
    n = mu.shape[0]; det = np.linalg.det(Sigma); inv = np.linalg.inv(Sigma)
    coeff = 1/(((2*np.pi)**(n/2))*np.sqrt(det))
    diff = X - mu
    exp = np.exp(-0.5*np.sum(diff.dot(inv)*diff, axis=1))
    return coeff*exp

# suspect: tall but light (170cm, 45kg) — unusual combination even if each alone plausible
suspect = np.array([[170, 45], [195, 90], [170, 70]])
print("independent product:", p_multivariate_independent(suspect, mu, sig))
print("multivariate (Σ):", p_multivariate_full(suspect, mean, Sigma))
# independent misses that height/weight should correlate; full Σ flags 170/45 as rarer.
● ● ●python — tune ε to maximize F1 (validation with known anomalies)
# validation: 100 normal + 5 known frauds (far points)
X_val = np.vstack([X_norm[:100], np.array([[200,50],[150,95],[190,40],[210,100],[145,45]])])
y_val = np.array([0]*100 + [1]*5)   # 1=anomaly

probs = p_multivariate_full(X_val, mean, Sigma)   # anomaly → tiny prob

def f1(y_true, y_pred):
    tp=np.sum((y_true==1)&(y_pred==1)); fp=np.sum((y_true==0)&(y_pred==1)); fn=np.sum((y_true==1)&(y_pred==0))
    prec=tp/(tp+fp) if tp+fp>0 else 0; rec=tp/(tp+fn) if tp+fn>0 else 0
    return 2*prec*rec/(prec+rec) if prec+rec>0 else 0

best_e, best_f=0,0
for eps in np.logspace(-8, -2, 50):
    pred = (probs < eps).astype(int)
    score = f1(y_val, pred)
    if score > best_f: best_f, best_e = score, eps
print(f"best ε={best_e:.2e}  F1={best_f:.3f}")

⭐ exam tip
Write gaussian formula + P(x)<ε rule + Π product, then drop: "multi-feature assumes independence; multivariate uses Σ for correlated features" + "choose ε by maximizing F1 on validation". That paragraph is page-32 examiner catnip.
⚠️ gotcha
Fit μ,σ on CLEAN data only. Train on data polluted with fraud and the bell learns fraud is normal → garbage in, bell out. Also: when $\sigma$ tiny for a feature, that feature dominates product — standardize? For anomaly you often keep raw scale, but beware.

quick check

  • P(x)=0.0001, ε=0.01? Anomaly (below threshold).
  • Height and weight correlated — which model? Multivariate gaussian (Σ captures tilt).
  • Fit μ,σ on what data? Only normal examples — anomalies excluded from training.
  • Three ML anomaly models named in notes? Isolation Forest, One-Class SVM, Autoencoders.

the 20-second answer

Anomaly detection = learn normal's bell(s) (μ,σ or Σ), flag P(x)<ε. Multiply per-feature bells if independent; use multivariate bell with Σ when features correlate (Mahalanobis distance). Tune ε to maximize F1. Multi-feature ≠ multivariate. 🎓 That closes the full ML arc — from drawing one line to spotting the lonely fraud.
