logistic draws any line that separates. SVM draws the street — the widest line that separates. same data, braver boundary.

the 30-second idea

Support Vector Machine (linear) finds the separating hyperplane with maximum margin. Imagine two classes as two crowds and you must lay a road between them — SVM picks the widest road so the next person (test point) is least likely to be mis-placed. The road edges touch the closest points — those points are the support vectors (they alone define the road; move any other point and nothing changes).

formulation — the optimization your notes skip but interviews don't

Hard-margin (perfectly separable) SVM:

$$\min_{w,b}\,\frac12\|w\|^{2}\quad\text{s.t. }\;y^{(i)}(w^{\top}x^{(i)}+b)\ge 1\;\;\forall i$$
minimize $\|w\|$ ⇔ maximize margin $2/\|w\|$ · every point ≥1 beyond its side, $y\in\{-1,+1\}$

Real data is never perfectly separable → soft-margin (what we implement): allow violations with slack ξ but pay for them. Equivalent hinge-loss form (the code's actual objective):

$$J(w,b)=\lambda\|w\|^{2}+\frac{1}{m}\sum_{i=1}^{m}\max\!\left(0,\,1-y^{(i)}(w^{\top}x^{(i)}+b)\right)$$
L2 penalty  ·  hinge loss (0 if $y(w^{\top}x+b)\ge 1$, else linear)

Relationship: $\lambda$ here behaves like 1/C in sklearn. Small $\lambda$ (or large C) → trust data, narrow margin, may overfit. Large $\lambda$ (small C) → wide margin, more violations allowed, simpler.

gradient? sub-gradient — hinge is kinky

Hinge $max(0, 1 - y\cdot (w\cdot x+b))$ is non-differentiable at the kink (=1). We use sub-gradient (pick a valid slope at the kink). For one example:

$$\begin{cases} y^{(i)}(w^{\top}x^{(i)}+b)\ge 1: & \nabla_{w}=2\lambda w,\; \nabla_{b}=0 \\ \text{else}: & \nabla_{w}=2\lambda w - y^{(i)}x^{(i)},\; \nabla_{b}=-y^{(i)} \end{cases}$$

This is exactly the if condition in your Ml_algos_scratch SVM.

⚠️ gotcha
Labels must be −1 / +1, not 0/1. Logistic uses 0/1, SVM uses −1/+1 so that $y\cdot (w\cdot x+b)$ carries sign correctness. Forgetting the conversion y = np.where(y==0,-1,1) is the #1 bug. Also: don't regularize b (no db penalty).

python from scratch — linear SVM (SGD style) + visualization

From Ml_algos_scratch/Ml/SVM_linear.ipynb, cleaned (variable names fixed, loop comments, predict isolated). SGD = one example at a time (as in notebook) → works for large data.

● ● ●python — linear SVM from scratch (hinge + L2, SGD)
import numpy as np
from sklearn.datasets import make_blobs
import matplotlib.pyplot as plt

# ── 1. toy blobs (2-D, linearly separable-ish)
X, y = make_blobs(n_samples=100, random_state=42, centers=2, cluster_std=1.2)
y = np.where(y==0, -1, 1)   # ★ 0/1 → -1/+1

n_samples, n_features = X.shape
epochs = 1000
alpha = 0.01          # learning rate
lambda_param = 0.01   # L2 strength (↔ 1/C). try 0.001,0.01,0.1

w = np.zeros(n_features)
b = 0.0

# ── 2. SGD training — one example at a time
for epoch in range(epochs):
    for idx, x_i in enumerate(X):
        condition = y[idx] * (np.dot(x_i, w) + b) >= 1
        if condition:
            dw = 2 * lambda_param * w       # outside margin → just decay
            db = 0
        else:
            dw = 2 * lambda_param * w - np.dot(x_i, y[idx])  # inside/wrong → decay + push
            db = -y[idx]
        w -= alpha * dw
        b -= alpha * db

def predict(X):
    return np.sign(np.dot(X, w) + b)   # -1 or +1

pred = predict(X)
acc = np.mean(pred == y)
print(f"accuracy {acc:.3f}  w={np.round(w,3)}  b={b:.3f}")
● ● ●python — class version (drop-in reusable) + plot street
class SVM:
    def __init__(self, alpha=0.01, lambda_param=0.01, epochs=1000):
        self.alpha = alpha; self.lambda_param = lambda_param; self.epochs = epochs
    def fit(self, X, y):
        n_samples, n_features = X.shape
        self.w = np.zeros(n_features); self.b = 0
        for _ in range(self.epochs):
            for idx, x_i in enumerate(X):
                if y[idx]*(np.dot(x_i,self.w)+self.b) >= 1:
                    dw = 2*self.lambda_param*self.w; db=0
                else:
                    dw = 2*self.lambda_param*self.w - y[idx]*x_i; db=-y[idx]
                self.w -= self.alpha*dw; self.b -= self.alpha*db
    def predict(self, X): return np.sign(X.dot(self.w)+self.b)

# ── visualize street: w·x+b = 0, ±1
def plot_street(X, y, model):
    def hline(x, w, b, off): return (-w[0]*x - b + off)/w[1]
    fig, ax = plt.subplots()
    ax.scatter(X[:,0], X[:,1], c=np.where(y==1,'#2b7de9','#ff6b35'), s=60, edgecolors='#1c1a15')
    x0a, x0b = X[:,0].min(), X[:,0].max()
    ax.plot([x0a,x0b],[hline(x0a,model.w,model.b,0),hline(x0b,model.w,model.b,0)],'--',color='#1c1a15',label='w·x+b=0')
    ax.plot([x0a,x0b],[hline(x0a,model.w,model.b,-1),hline(x0b,model.w,model.b,-1)],'k-',linewidth=1)
    ax.plot([x0a,x0b],[hline(x0a,model.w,model.b,1),hline(x0b,model.w,model.b,1)],'k-',linewidth=1)
    ax.legend(); plt.show()

m = SVM(); m.fit(X,y); plot_street(X,y,m)

quick check

  • What are support vectors? Points exactly on the street edges ($y(w\cdot x+b)=1$) — they alone determine the boundary.
  • Why −1/+1 not 0/1? So $y\cdot score$ encodes correctness + confidence in one product.
  • Hinge = 0 when? When point is correct and at least 1 unit beyond the line (outside street).
  • SVM loss vs logistic? Hinge is 0 beyond margin (sparse), logistic never zero (all points matter).

the 20-second answer

Linear SVM = max-margin street found by minimizing hinge + L2: $\lambda||w||^{2} + \sum max(0,1-y(w\cdot x+b))$. SGD updates: if outside margin just decay, else decay + push. Only support vectors on ±1 edges matter. Next: data that can't be separated by any straight street — we bend space itself → SVM Poly Kernel.
