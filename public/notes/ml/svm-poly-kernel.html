some dots sit in a ring — no straight street can cut them. lift the paper, the ring becomes a hill, a plane cuts it. that's the kernel trick.

the 30-second idea

Linear SVM fails when classes look like concentric circles, XOR, or moons — no line separates them. Two ways out: (1) explicit polynomial features — engineer $[x_{1}, x_{2}, x_{1}^{2}, x_{2}^{2}, x_{1}\cdot x_{2}]$ and run linear SVM in 5-D; (2) kernel trick — never build 5-D explicitly, compute dot-products in high-D via a kernel function. Your Ml_algos_scratch/Ml/SVM_poly_kernel.ipynb implements (1) fully and visualizes the lift into 3-D; this page teaches both so you can answer either exam question.

explicit polynomial expansion — what the notebook actually does

Original: [x₁, x₂] (2-D). Transform:

$$\phi(x)=\left[x_{1},\,x_{2},\,x_{1}^{2},\,x_{2}^{2},\,x_{1}x_{2}\right]^{\top}\in\mathbb{R}^{5}$$
degree-2 polynomial lift · degree-3 adds cubes, dimensions explode

In 5-D, circles become linearly separable. Train a plain linear SVM on \phi(x) — the notebook does exactly that and gets 100% accuracy on make_circles.

● ● ●python — explicit \phi + linear SVM (from notebook)
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_circles

# 1. rings: outer vs inner — no line can separate
X, y = make_circles(n_samples=300, noise=0.05, random_state=42, factor=0.3)
y = np.where(y==0, -1, 1)
plt.scatter(X[:,0], X[:,1], c=np.where(y==1,'#2b7de9','#ff6b35'), s=18); plt.title("rings — linear fails"); plt.show()

# 2. explicit polynomial lift \phi: [x1,x2,x1²,x2²,x1·x2]  (degree 2)
X_poly = np.column_stack([X[:,0], X[:,1],
                          X[:,0]**2, X[:,1]**2,
                          X[:,0]*X[:,1]])
print(X_poly.shape)  # (300, 5)

class SVM:
    def __init__(self, alpha=0.001, lambda_param=0.01, epochs=1000):
        self.alpha=alpha; self.lambda_param=lambda_param; self.epochs=epochs
    def fit(self, X, y):
        n_samples, n_features = X.shape
        self.w=np.zeros(n_features); self.b=0
        for _ in range(self.epochs):
            for idx, x_i in enumerate(X):
                if y[idx]*(np.dot(x_i,self.w)+self.b) >= 1:
                    dw=2*self.lambda_param*self.w; db=0
                else:
                    dw=2*self.lambda_param*self.w - y[idx]*x_i; db=-y[idx]
                self.w -= self.alpha*dw; self.b -= self.alpha*db
    def predict(self, X): return np.sign(np.dot(X,self.w)+self.b)

model = SVM(); model.fit(X_poly, y)
print("acc", np.mean(model.predict(X_poly)==y))  # 1.0 ★
print("learned w", np.round(model.w,2))   # w for x1²,x2² large positive → bowl

# z = x1² + x2²  (collapse x1² and x2² into one height for 3-D plot)
fig = plt.figure(figsize=(9,6)); ax = fig.add_subplot(111, projection='3d')
Z = X[:,0]**2 + X[:,1]**2

ax.scatter(X[y==-1,0], X[y==-1,1], Z[y==-1], color='#ff6b35', label='inner')

# plane: w0·x1 + w1·x2 + w2·x1² + w3·x2² + w4·x1x2 + b = 0 → approx as w_mean·z + ...
w_mean = (model.w[2]+model.w[3])/2
xx, yy = np.meshgrid(np.linspace(X[:,0].min(), X[:,0].max(), 30),
                     np.linspace(X[:,1].min(), X[:,1].max(), 30))
zz = (-model.w[0]*xx - model.w[1]*yy - model.w[4]*xx*yy - model.b)/ (w_mean + 1e-9)
ax.plot_surface(xx, yy, zz, alpha=0.25, color='#ffe14d')
ax.set_xlabel('x1'); ax.set_ylabel('x2'); ax.set_zlabel('z = x1²+x2²')
ax.set_title('explicit \phi lifts rings into hill — plane separates'); ax.legend(); plt.show()

The notebook's 30-grid plane is an approximation (averaging w₂,w₃). Exact \phi would be 5-D and can't be plotted, so we collapse to 3-D for intuition — the idea holds.

kernel trick — when explicit \phi explodes

Degree-2 poly on 100 features → ~5,000 dimensions. Degree-3 → ~170k. Explicit \phi becomes impossible. Kernel trick avoids building \phi at all.

$$K(x,z)=\left(x^{\top}z + c\right)^{d}=\phi(x)^{\top}\phi(z)$$
dot-product in high-D via kernel in low-D · solve dual with $K$ only
kernelK(x,z)\phi dimensionwhen
Linear$x\cdot z$nalready separable
Poly (d=2)$(x\cdot z + 1)^{2}$~ n²/2circles, XOR, curves
Poly (d=3)$(x\cdot z+1)^{3}$~ n³/6more wiggly boundaries
RBF/Gaussianexp(−γ||x−z||²)infinite ★smooth blobs around points (next level)

Interview one-liner: "Explicit \phi builds features then does $w\cdot \phi(x)$; kernel computes $\phi(x)\cdot \phi(z)$ directly via K(x,z) in the dual, so SVM training never leaves low-D." Dual variables are α_i (one per example); only support vectors get α_i>0.

● ● ●python — kernel matrix (poly degree 2) — no \phi built
def poly_kernel(X, Z, degree=2, c=1.0):
    return (X.dot(Z.T) + c) ** degree   # K[i,j] = (x_i·z_j + c)^d

K = poly_kernel(X, X, degree=2, c=1)
print(K.shape)   # (300,300) — all pairs kernel
# check: first two points dot vs kernel
x, z = X[0], X[1]
phi_x = np.array([x[0], x[1], x[0]**2, x[1]**2, x[0]*x[1]])
phi_z = np.array([z[0], z[1], z[0]**2, z[1]**2, z[0]*z[1]])
# not equal exactly — kernel implicitly uses scaled \phi (√2 factors) but same geometry
print("kernel", (np.dot(x,z)+1)**2, "explicit dot", np.dot(phi_x, phi_z))
explicit \phi = engineer features yourself, then linear SVM.  ·  kernel = skip \phi, compute K(x,z) in dual.  ·  both learn curved boundaries in original space.

⚠️ gotcha
Don't forget to standardize BEFORE polynomial expansion — otherwise x₁² explodes scale and GD diverges. Also: polynomial degree too high → overfit (wiggly boundary memorizes noise). Use validation to pick $d=2 vs 3$.
🔬 try it: degree matters — d=1 vs d=2 vs d=3

Run same X,y: train linear (d=1) → ~50% acc (fails). d=2 → 100% (perfect ring). d=3 → also ~100% but boundary wigglier. Try adding 10% label noise → d=3 overfits more. That's the bias-variance tradeoff in kernel space.

def make_poly(X,d):
    if d==1: return X
    if d==2: return np.column_stack([X[:,0],X[:,1],X[:,0]**2,X[:,1]**2,X[:,0]*X[:,1]])
    # d=3: add cubes + triple cross terms (simplified subset)
    return np.column_stack([X[:,0],X[:,1],X[:,0]**2,X[:,1]**2,X[:,0]*X[:,1],X[:,0]**3,X[:,1]**3])

for d in [1,2,3]:
    Xd=make_poly(X,d); m=SVM(alpha=0.001,epochs=800); m.fit(Xd,y)
    print(f"d={d} acc={np.mean(m.predict(Xd)==y):.2f}  |w|={np.linalg.norm(m.w):.1f}")

quick check

  • Why lift to 5-D? → Circles become linearly separable; linear SVM in 5-D = curved circle in 2-D.
  • Kernel trick one line? → Compute high-D dot-product via low-D kernel: $K(x,z)=(x\cdot z+1)^{2} = \phi(x)\cdot \phi(z)$, never build \phi.
  • Which kernel has infinite \phi? → RBF exp(−γ||x−z||²).

the 20-second answer

Non-linear data → lift with \phi(x)=[x₁,x₂,x₁²,x₂²,x₁x₂] (explicit) and train linear SVM, or use poly kernel $K=(x\cdot z+c)^d$ to stay in low-D (kernel trick). Your notebook builds \phi explicitly and gets 100% on rings; kernel does the same implicitly for any degree. Next: how to score any classifier honestly when data is skewed → Precision, Recall & F1.
