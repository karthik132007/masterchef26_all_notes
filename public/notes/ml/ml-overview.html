the 30-second idea

Machine Learning = learn the mapping from data instead of hand-coding rules. You show the machine thousands of $(x \to y)$ pairs and it invents the function. Three tribes, straight from your page 2 of ml1.pdf:

  • Supervised — you hand over questions + correct answers → learn to mimic. Hero of this track.
  • Unsupervised — only questions, no answers → discover hidden structure.
  • Reinforcement — no dataset, only a world + reward button → learn by trying.

🧷 remember
Supervised is "copy the answer sheet". Unsupervised is "find the cliques in the canteen with no seating plan." Reinforcement is "touch the stove, learn fast." If you can tell those stories, you'll never confuse them in an exam.
⭐ exam tip
Regression = number (infinite outputs). Classification = category (finite outputs). "Predict price" → regression; "spam or not" → classification. One line, full marks, examiners copy-paste this.

train vs test — why good students don't cheat

Never evaluate on the data you trained on — that's like giving the exam with the answer sheet attached. Split:

splitsizetouch when?used for
Train~60-70%every GD steplearn w,b
Validation~15-20%after trainingtune λ, α, K, ε
Test~15-20%once at the endhonest final score

Overfitting = memorises train, fails test (too wiggly). Underfitting = fails both (too simple). Just right = low on both. That triangle is the whole ball game for later pages on regularization, trees, and SVMS.

⚠️ gotcha
ŷ (y-hat) vs y: y is truth, ŷ is your model's guess. The entire cost function is just "how far is ŷ from y". Keep them apart and gradient descent, logistic loss and SVM hinge loss all make sense instantly.

quick check

  • Email → spam? Supervised — which branch? → Classification (finite answers).
  • Group shoppers with no labels? → Unsupervised → clustering.
  • What is m? → # training examples (deck size). n? → #features per example.
  • Why split off a test set? → To prove you didn't just memorise training.

the 20-second answer

Supervised learns $x \to y$ from labelled pairs and splits into regression (numbers) vs classification (categories). Unsupervised gets only X and finds clusters, anomalies or compressions. Workflow is data → model → cost → optimize → evaluate, and the alphabet is x, y, m, ŷ, w, b — everything after this page is just those letters dancing. Next → Linear Regression: f(x)=wx+b.
