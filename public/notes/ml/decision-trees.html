the 30-second idea

Pages 21–24: a decision tree is supervised classification as a flowchart. Your notes' running example: cat vs dog from ear shape, face shape, whiskers. Each node asks the question that purifies the crowd fastest — measured by entropy drop (information gain). One tree overfits; a forest votes it sane; boosting stacks fixers.

entropy: the mess-meter (page 23)

Entropy measures impurity: 0 = pure room (all cats 😻), 1 = chaos (half cats, half dogs 🙀🐶). Goal of every split: reduce entropy.

$$H(p_{1})=-p_{1}\log_{2}p_{1}-(1-p_{1})\log_{2}(1-p_{1}),\quad H=0\;\text{pure},\;H=1\;\text{50/50 chaos}$$

information gain: pick the best question

$$\text{IG}=H(\text{root})-\sum_{c}\tfrac{|c|}{|\text{root}|}H(c)\quad\text{pick }\max \text{IG }\Rightarrow\text{ split, recurse}$$

Your notes' build loop: entropy of root → try each feature → weighted child entropy → IG → best wins → repeat until pure ($H=0$), no features left, or max depth reached.

import numpy as np

# 3 binary features: 0 cap brown?, 1 stalk tapering?, 2 solitary?
X_train = np.array([[1,1,1],[1,0,1],[1,0,0],[1,0,0],[1,1,1],
                [0,1,1],[0,0,0],[1,0,1],[0,1,0],[1,0,0]])
y_train = np.array([1,1,0,0,1,0,0,1,1,0])
# y=1 edible, 0 poisonous

def entropy(y):
    if len(y)==0: return 0
    p1 = np.sum(y==1)/len(y)
    if p1==0 or p1==1: return 0
    return -p1*np.log2(p1) - (1-p1)*np.log2(1-p1)

print("root entropy", entropy(y_train))  # ~0.97 (5-5 split)
● ● ●python — split + information gain + best split
def split_data(X, node_indices, feature):
    left, right = [], []
    for i in node_indices:
        if X[i][feature]==1: left.append(i)
        else: right.append(i)
    return left, right

def info_gain(X, y, node_indices, feature):
    left_idx, right_idx = split_data(X, node_indices, feature)
    if len(left_idx)==0 or len(right_idx)==0: return 0
    y_node, y_left, y_right = y[node_indices], y[left_idx], y[right_idx]
    w_left = len(left_idx)/len(node_indices)
    w_right= len(right_idx)/len(node_indices)
    return entropy(y_node) - (w_left*entropy(y_left) + w_right*entropy(y_right))

def get_best_split(X, y, node_indices, used_features):
    best_f, best_ig = -1, 0
    for f in range(X.shape[1]):
        if f in used_features: continue
        ig = info_gain(X, y, node_indices, f)
        if ig > best_ig: best_ig, best_f = ig, f
    return best_f

root = list(range(10))
for f in range(3):
    print(f"IG feature {f}: {info_gain(X_train,y_train,root,f):.4f}")
# feature 2 (solitary) wins → root splits on 2

● ● ●python — recursive tree builder (prints readable rules)
def build_tree(X, y, node_indices, branch_name, cur_depth, max_depth, used_features):
    # 1. pure node?
    if len(set(y[node_indices]))==1:
        print("-"*cur_depth, f"{branch_name} leaf (pure) class={y[node_indices][0]}")
        return
    # 2. max depth reached?
    if cur_depth==max_depth:
        print(" "*cur_depth+"-"*cur_depth, f"{branch_name} leaf depth-limit {node_indices}")
        return
    best = get_best_split(X, y, node_indices, used_features)
    used_features.add(best)
    print(f"{'-'*cur_depth} Depth {cur_depth}, {branch_name}: split on feature {best}")
    left, right = split_data(X, node_indices, best)
    if len(left)==0 or len(right)==0:
        print("-"*cur_depth, f"{branch_name} leaf (no split)"); return
    build_tree(X, y, left,  "left",  cur_depth+1, max_depth, used_features.copy())
    build_tree(X, y, right, "right", cur_depth+1, max_depth, used_features.copy())

build_tree(X_train, y_train, root, "Root", cur_depth=0, max_depth=2, used_features=set())

Feed a new mushroom [1,0,0] → follow: solitary=no → right branch → stalk not tapering → $leaf=0$ poisonous. Every root-to-leaf path is one if-then rule you can explain to a doctor — that interpretability is why trees survive in healthcare/finance.

one tree overfits → plant a forest (bagging)

Random Forest recipe: sample rows with replacement (bootstrap) + sample random subset of features at each split → build many trees fully → average (regression) or majority vote (classification). Out-of-bag (unused rows) gives free validation.

gradient boosting — sequential fixers

$$\begin{aligned} &1.\;\text{fit weak tree} \\ &2.\;\text{residual }r=y-f \\ &3.\;\text{next tree fits }r \\ &4.\;\text{repeat }\Rightarrow\text{ stronger } \end{aligned}\qquad \text{Forest: parallel bag+vote, Boosting: serial fixers}$$

Boosting reduces bias aggressively but overfits if you boost too long → early stopping on validation.

stopping rules & pruning — how to not memorize

  • Stop early: pure node, no features left, max_depth, min_samples_split, min IG gain.
  • Prune after: grow full tree then cut branches that don't improve validation.
  • Rule of thumb: max_depth 3–7 for tabular data; deeper → memorizes noise.
⭐ exam tip
Entropy 0=pure; IG picks max; single tree overfits, forest fixes variance by vote. Boosting = sequential residual fix. For mushroom: feature 2 wins at root (IG≈0.278). Write H formula + IG formula + one split calculation — that's the derivation examiners want.
⚠️ gotcha
Deeper ≠ better. Growing till every leaf is pure memorizes noise (like regularization λ=0). Use max_depth / IG threshold. Also: info gain biased to high-cardinality features (many distinct values) → use gain ratio or just be aware.

  • Forest regression combines how? Average. Classification? Majority vote.
  • Forest vs boosting — parallel or serial? Forest parallel (bagging); boosting serial (fix errors).

the 20-second answer

Trees ask the purifying question at each node (max IG = biggest entropy drop) till leaves are pure or limits hit. One tree overfits; random forests bag random samples + vote for stability (variance down); boosting stacks weak fixers serially (bias down). Next: no labels at all → Clustering & K-Means.
