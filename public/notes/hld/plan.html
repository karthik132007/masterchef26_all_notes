HLD, Concept by Concept

No day-wise grind here. This track follows the natural scaling journey from a single server monolith all the way to distributed microservices: one focused design note per idea. Deep dive, interview-ready trade-offs.

The 0 to 10M user scaling progression:
  1. Start simple: Single process, in-memory nanosecond calls, and the Modular Monolith
  2. Scale horizontally: Spread traffic across $N$ servers with Layer 4 & Layer 7 Load Balancers
  3. Guard the perimeter: API Gateways for edge auth, Token Bucket rate limiting, and BFFs
  4. Accelerate reads: Sub-millisecond RAM caching (Redis) and beating the 3 Cache Disasters
  5. Scale persistent state: SQL vs NoSQL, storage engine internals, and primary-replica replication
  6. Shard across hardware: Horizontal partitioning, shard key selection, and Consistent Hashing
  7. Decompose at organizational scale: Microservices, Database-per-service, Sagas, and Circuit Breakers
  8. Decouple & scale asynchronously: Message Queues & Event Streaming (SQS, Kafka & RabbitMQ)
  9. Package & isolate at scale: OS virtualization, Linux primitives (Namespaces, Cgroups) & Docker
