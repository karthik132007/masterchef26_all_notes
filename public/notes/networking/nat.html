the 30-second idea

NAT (Network Address Translation) is a routing technique that rewrites the source or destination IP addresses and ports inside packet headers while in flight.

🏨 The Grand Hotel Mailroom Analogy

Imagine a hotel with 500 guests staying in rooms 101 through 600:

  • No guest has a public street address. Amazon delivery drivers cannot drive directly to "Room 304".
  • The Hotel Front Desk: Has one single public street address: 742 Evergreen Terrace (The Public IP).
  • Ordering Mail: When Alice in Room 304 sends a letter, the hotel mailroom clerk crosses out "Room 304", writes the hotel's public address, and stamps a private tracking ticket number on the envelope: Ticket #61001. The clerk records in the logbook: Ticket 61001 ↔ Room 304.
  • The Return Delivery: When a reply arrives addressed to 742 Evergreen Terrace (Attn: Ticket 61001), the clerk looks up the logbook, crosses out the ticket number, writes "Room 304", and slides it under Alice's door.
🧷 remember
RFC 1918 Private IPs (192.168.x.x, 10.x.x.x, 172.16.x.x) are strictly non-routable on the public internet. The moment a packet hits your router, NAT swaps the private IP for the router's public WAN IP!

the p2p problem: webrtc stun, turn & ice

Because NAT drops all incoming packets that don't match an existing outgoing session in its table, two private devices behind different home routers cannot easily talk directly to each other! This breaks direct video calls (Zoom, WebRTC) and gaming.

To solve this, the networking industry built NAT Traversal:

ProtocolFull NameRole in Peer-to-Peer Connection
STUN Session Traversal Utilities for NAT The Mirror: A lightweight public server that tells the client: "Hey, your router translated your internal IP to public IP 203.0.113.1 on port 61001!" The client shares this reflexive address with its peer to attempt direct UDP hole-punching.
TURN Traversal Using Relays around NAT The Fallback Relay: If routers use strict "Symmetric NAT" that blocks hole-punching, direct P2P is impossible. Both clients stream all encrypted audio/video through a cloud TURN relay. (Costs bandwidth, but 100% reliable).
ICE Interactive Connectivity Establishment The Framework: Tries direct LAN connection first → attempts STUN hole-punching → falls back to TURN relay if all else fails.

managing nat on linux with iptables & conntrack

# 1. Inspect live NAT translation connections in the Linux kernel
sudo conntrack -L

# 2. Add an outbound SNAT masquerade rule on WAN interface (eth0)
sudo iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE

# 3. Add an inbound DNAT (Port Forwarding): Forward public port 80 to internal IP 192.168.1.50:8080
sudo iptables -t nat -A PREROUTING -p tcp --dport 80 -j DNAT --to-destination 192.168.1.50:8080
⭐ viva & interview question
Q: What is Carrier-Grade NAT (CGNAT) and why does it break home hosting?
A: Because ISPs also ran out of public IPv4 addresses, they place home routers behind another layer of NAT at the ISP data center (using the shared 100.64.0.0/10 IP range). Your router's WAN IP is not public! As a result, standard port forwarding on your home router will fail to expose services to the internet, forcing developers to use tunnels like Cloudflare Tunnels, Tailscale, or ngrok.
